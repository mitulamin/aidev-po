# Lean Canvas

Capture the nine-box Lean Canvas concisely on one page, trace every box to evidence tags, and isolate the riskiest hypotheses first.

## When to use

During the `idea` stage to turn an initial product concept into a testable one-page hypothesis model.

## Producer: dos and don'ts

Do:
- Fill all nine boxes concisely with stable IDs (`IDEA-NNN`): Problem (top 1-3 + existing alternatives), Customer Segments (early adopters vs broad market), Unique Value Proposition (plus high-level concept), Solution (top 3 capabilities), Channels, Revenue Streams, Cost Structure, Key Metrics, Unfair Advantage
- Tag every entry in every box with `[Stated]`, `[Inferred]`, `[Assumed]`, or `[Validated]`
- Highlight the top 3 riskiest assumptions (highest impact if wrong, lowest current evidence) and send them to the register
- Consider "what if nothing is built?" (status quo baseline in Existing Alternatives)

Don't:
- Treat the Lean Canvas as a static truth document; every unverified box is a hypothesis
- Copy vague buzzwords into Unfair Advantage (e.g. "passion", "first mover", "clean UI")
- Propose solutions before naming the top 1-3 problems and existing alternatives

## Steps

1. Populate Problem + Existing Alternatives and Customer Segments + Early Adopters first.
2. Draft Unique Value Proposition and high-level concept, then minimal Solution capabilities.
3. Complete Channels, Revenue Streams, Cost Structure, Key Metrics, and Unfair Advantage (or mark `None yet [Assumed]`).
4. Rank the riskiest assumptions across all 9 boxes and emit `[ASSUMPTION: ...]` / `[QUESTION: ...]` items.

## Self-check

- [ ] Are all 9 boxes present with stable IDs (`IDEA-NNN`) and evidence tags?
- [ ] Are Existing Alternatives (including doing nothing / manual workarounds) explicitly documented?
- [ ] Are the riskiest assumptions explicitly ranked and sent to the register?

## Adversarial reviewer

- Fail if any box is missing, untagged, or relies on unacknowledged assumptions presented as facts.
- Flag solutions that do not map back to a stated Problem or Customer Segment.
- Flag fake Unfair Advantages (traits easily copied on day one) not marked `[Assumed]`.
