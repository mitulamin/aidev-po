# Licensing notes

This repo uses three licences, the same split as [ai-sdlc-loop](https://github.com/mitulamin/ai-sdlc-loop). This is not legal advice.

## GPL-3.0 (code)

The text is in [LICENSE](LICENSE). It covers:

- `scripts/`
- `schemas/` (JSON Schema files are treated as code)
- `tests/`, including the fictional fixture products repo under `tests/fixtures/`
- tooling, including workflow files under `.github/workflows/`

Do not replace or edit `LICENSE` without a deliberate decision.

## CC BY-SA 4.0 (writing)

The text is in [LICENSE-CONTENT](LICENSE-CONTENT). It covers markdown and other writing outside `templates/`:

- `agents/`, `skills/`, `commands/` (the sources)
- `docs/`
- `examples/`
- `README.md`, `AGENTS.md`, `CONTRIBUTING.md`, and this file
- `.cursor/`: these files are generated by `scripts/build-agents.py` from the sources above and carry the licence of those sources

Each file is under one licence.

The aidev-po logo (the Lens mark in `docs/assets/aidev-po.svg`, its PNG exports and `docs/favicon.ico`) and the rest of the `docs/` site content are CC BY-SA 4.0, copyright Shravi Limited and contributors. Credit them if you reuse the logo or the writing.

## MIT (templates)

The text is in [templates/LICENSE](templates/LICENSE). It covers everything under `templates/`, code and writing. Templates are meant to be copied into your own product folders, so they start under MIT, not GPL.

## Your products are yours

Whatever you put in your products repo (outside this checkout) is not part of this repo and is not covered by any licence here. Using aidev-po to produce it does not make it GPL or CC BY-SA. Licence your products repo however you like.

Agent and skill output is only as good as the inputs you gave. Do not paste material into a product you cannot license the way you intend.

Content borrowed from other projects keeps its original licence and is credited next to the file that uses it. This repo does not relicense it.
